Patch one thing inside a list

MODS. A mod used to have to rewrite a whole list to change one item in it. Now it names the item. Nothing is built into the game.
A SKILL, BY ITS NAME
"knife": { "skills": {
  "Stab": { "ap": 3 } } }
Stab costs 3 action points. The other skill and Stab's fatigue stay.
A PERK, ADDED AND REMOVED
"brigand_poacher": { "perks": {
  "add": ["Nimble"],
  "remove": ["Rotation"] } }
Lists of plain words take add and remove. Nothing else moves.
A MAN IN A START, BY POSITION
"rebuild": { "men": {
  "0": { "level": 3 } } }
Some lists have no names. Count from zero.
OR REPLACE THE WHOLE LIST
"skills": [ { "name": "Only", ... } ]
An array still replaces everything, as before.
Only 3 lists in the data hold objects. The other 29 are plain words. Both are covered. No rule, no limit.
