# FACE REFERENCES (a portrait at 64px)

### FACE-01  Portraits — Pedro Medeiros (saint11)
- WHERE: https://lospec.com/pixel-art-tutorials/portraits-by-pedro-medeiros
- KIND: pixel
- TEACHES: at portrait scale the eyes carry the face; one pixel of eye spacing changes identity more than any amount of shading.

### FACE-02  The vertical thirds (classical construction, any figure-drawing text)
- WHERE: search "facial proportions thirds construction" (structure only)
- KIND: real
- TEACHES: hairline-brow, brow-nose, nose-chin are equal thirds; the eye line is halfway down the skull; a face that breaks the thirds reads as a caricature whether you meant it or not.

### FACE-03  The repo's own face law (identity at 64px)
- WHERE: laws/BOHEMIA_LAW_EVERYBODY_HAS_A_FACE_8_27_26.md
- KIND: real
- TEACHES: identity at small sizes is SIZE AND SPACING, not detail — the same channel face recognition uses; cheeks widest, jaw inside them, chin inside the jaw.
