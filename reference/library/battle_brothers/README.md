# THE BATTLE BROTHERS LIBRARY (rule 33j, Paolo 9/27: "download everything or remember everything, all the stats")
Battle Brothers is the reference for the campaign layer, the overworld map, travel, events, places and the
company (its fight is flavour only; Rogue Fable 4 leads the fight). Every [bb ...] school line reads this
library FIRST and cites the file it used; a lane that finds a number wrong fixes it here with a source.

are allowed, PLUMBER [bb library] pulls every wiki page and dev blog to text under wiki/ and blog/, and the
volumes cite them.
