# ASK 79 LATE GAME CRISES THE WAY BATTLE BROTHERS DOES IT

## PAOLO SAID IN THIS CHAT
Late game crises stay the way Battle Brothers does it.

## MY PROPOSAL
Battle Brothers has four late game crises. The player can choose the first one or leave it random. The first crisis is foretold around day fifty to seventy and starts around day eighty to one hundred if the company is strong enough. Each crisis has a buildup phase and a main phase. Completing one ends it and another can start later. The same crisis does not happen twice in a row. Some crises can destroy settlements if permanent destruction is on. The wiki does not list every strength requirement or exact duration for every crisis.

In Bohemia the same late game crises system stays. A translation vote is only when Paolo asked for that item.
