# ASK 62 LATE GAME CRISES THE WAY BATTLE BROTHERS DOES IT

## PAOLO SAID IN THIS CHAT
Late game crises stay the way Battle Brothers does it.

## MY PROPOSAL
Battle Brothers starts a late game crisis around day 80 to 100. The player can pick the first crisis or leave it random. There are four crises: noble war, undead scourge, greenskin invasion, and holy war. Each crisis has a buildup phase and a full phase with special contracts and events. Crises can destroy settlements if permanent destruction is on. The same crisis does not repeat back to back. The wiki does not list every edge case for every crisis.

In Bohemia the same late game crisis system stays. A translation vote is only when Paolo asked for that item.
