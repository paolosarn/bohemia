# ASK 125: The Narration Toggle

## PAOLO SAID IN THIS CHAT:

Read the whole master file. Narration on demand: one toggle in SETTINGS, off by default, and the machine voice reads any player-facing text aloud, a tap stops it, people keep their portrait mouths.

## MY PROPOSAL:

The master locks a narration toggle in Settings. It is off by default. When on, a machine voice reads any player-facing text. A tap stops the reading. Portrait mouths still move. The master does not lock the voice itself, the language, or which screens the toggle covers first.

Battle Brothers has no built-in narration. An accessibility mod called The Unseen Banner reads the game state aloud through NVDA or a SAPI voice. It covers the main menu, pause menu, events, and tactical combat. It is English only. The wiki does not say whether the base game supports any text-to-speech. The wiki does not say the font sizes or colour options that another accessibility mod exposes.

Bohemia has no locked rule that says the machine voice is a single analog-horror tone, a per-character voice that matches the portrait, or a system default. The master does not say whether the toggle reads tooltips, event text, and combat logs, or only event text. The master does not say whether the voice is generated at runtime or pre-recorded for the alpha.

A LITTLE THING FROM the Unseen Banner mod that already proves a screen-reader layer can sit on top of Battle Brothers without touching the base files.

WHAT IS CERTAIN: Toggle exists, off by default, reads any player-facing text, tap stops it, mouths still move.
WHAT IS NOT: Voice identity. Language. Screen priority. Runtime versus pre-recorded.
WHAT WE SHOULD ASK NEXT: Whether the first narration pass should cover only event text and tooltips.
