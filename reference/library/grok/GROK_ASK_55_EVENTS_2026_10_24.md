# ASK 55 EVENTS THE WAY BATTLE BROTHERS DOES IT

## PAOLO SAID IN THIS CHAT
Events stay the way Battle Brothers does it.

## MY PROPOSAL
Battle Brothers fires random events on the world map every few days. Events can need a background, a trait, an origin, a crisis, a contract, a place, or nothing. Each event has a score that sets its chance. Events can add or remove traits, raise stats, give gear, change mood, or start fights. Cooldowns keep the same event from repeating too soon. The wiki does not list every edge case for every event.

In Bohemia the same event system stays. A translation vote is only when Paolo asked for that item.

Sources: Battle Brothers wiki Events page, developer notes, and community event guides. The wiki does not say every edge case.
