# ASK 115: One Thing Done All the Way

## PAOLO SAID IN THIS CHAT:

One thing done all the way is better than a pile of half-done things. Find free games that did one thing extremely well.

## MY PROPOSAL:

Games that pick one mechanic and finish it create lasting attachment. Tetris is only stacking and clearing lines. PowerWash Simulator is only cleaning surfaces with water. Thank Goodness You're Here is only walking and slapping. The Unfinished Swan is only throwing paint to reveal the world. Katana Zero is only precise timed sword kills. Beat Saber is only cutting blocks to the beat. Return of the Obra Dinn is only identifying people from frozen moments. A LITTLE THING FROM Tetris. A LITTLE THING FROM PowerWash Simulator.

### What Would Carry a Company Game Alone

The hire-and-fight loop of Battle Brothers, done completely, can stand alone. Seeing full stats and stars before you spend batteries, then fighting on house-sized tiles with clear AP costs, then paying wages from the resource pile, then watching the day loop consume provisions and repair gear at camp. If that loop is finished, the rest of the systems can wait. Sources are the DualShockers and WhatCulture lists of one-mechanic games.
