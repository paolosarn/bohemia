# UI REFERENCES (an iPhone portrait screen)

### UI-01  Into the Breach (Interface In Game gallery)
- WHERE: https://interfaceingame.com/games/into-the-breach/
- KIND: pixel
- TEACHES: the game states everything it is about to do before it does it; a UI that makes the player remember instead of recognise is spending working memory the fight needs (our day-17 rule: words for the world, ONE number).

### UI-02  Game UI principles (Kukshtel)
- WHERE: https://kylekukshtel.com/game-ui-principles
- KIND: pixel
- TEACHES: UI is a conversation with one voice: every panel that invents its own layout grammar makes the player relearn the screen.

### UI-03  The phone itself (Apple Human Interface Guidelines, touch targets)
- WHERE: https://developer.apple.com/design/human-interface-guidelines
- KIND: real
- TEACHES: a touch target is 44pt minimum and the thumb lives at the bottom; anything he must reach for at the top of a portrait screen is a desktop habit wearing a phone costume.
