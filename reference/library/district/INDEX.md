# DISTRICT REFERENCES (a whole block or plot read at map zoom)

### DIST-01  SimCity 2000 building sprites
- WHERE: https://frontiernerds.com/simcity-2000-sprite-extraction
- KIND: pixel
- TEACHES: at map zoom a district reads by SILHOUETTE and ROOF PATTERN, not by wall detail; every sprite sits on the 2:1 isometric diamond and never breaks its own tile bounds.

### DIST-02  Learning From Las Vegas (Venturi/Scott Brown)
- WHERE: https://www.udg.org.uk/publications/udlibrary/learning-las-vegas
- KIND: real
- TEACHES: a Vegas commercial plot is SIGN + SHED + PARKING IN FRONT; the building hides behind its lot, so a district that puts the building on the street edge is drawn from the wrong city.

### DIST-03  Las Vegas aerial (any mapping satellite view)
- WHERE: https://www.google.com/maps/@36.1146,-115.1728,2000m (satellite)
- KIND: real
- TEACHES: a Sun Belt subdivision is a CUL-DE-SAC BULB ringed by one continuous block wall; an industrial plot is one big roof plus yard; the grain of the valley is the arterial mile grid.

### DIST-04  Stardew Valley town map (extracted sheets)
- WHERE: https://www.spriters-resource.com/pc_computer/stardewvalley/
- KIND: pixel
- TEACHES: in 3/4 top-down a building is FRONT FACE + ROOF BAND stacked, the door always touches the ground row, and paths read because they are one value lighter than the grass, not a different hue.

### DIST-05  Faux urbanism on the Strip (Themerica)
- WHERE: https://www.themerica.org/blog/2021/05/23/viva-las-vegas
- KIND: real
- TEACHES: real urban texture is LAYERED BY TIME (mismatched frontages, patched surfaces); a district where every building matches reads as a theme park, which is the exact wrongness Bohemia's dead world must avoid.
