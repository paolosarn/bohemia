# THE REFERENCE LIBRARY (DIRECTION lane, 9/5/26 — VAMILY [reference library])

One folder per asset kind. Each INDEX.md holds the best REAL and PIXEL
references for that kind, each with a one-line note of the STRUCTURAL RULE
it teaches. COOK and DIRECTION read from here; a cook's `REFERENCE CHECK:`
should name entries by their REF-ID (e.g. `DIST-01`) so the index job can
resolve the claim against a real entry.

THE LAW THIS SERVES: COMPARE EVERY PIECE OF ART TO THE WORLD (9/4, LOCKED).
Structure comes from reference; style comes from us.

THE BAN THAT RIDES WITH IT (8/28, LOCKED): NOTHING FROM THIS LIBRARY ENTERS
THE DESIGN VOCABULARY. A reference names its source the way a measurement
names its ruler. Comparing against another game's pixels for structural
correctness is ordered; bringing that game's name, mechanics, words or
aesthetic identity into Bohemia's design is banned. The reference set for
DESIGN is his alone: Rogue Fable 4, Battle Brothers, Final Fantasy XII,
plus the two fashion houses (Balenciaga, Rick Owens) he named 9/4.

ENTRY FORMAT (keep it exactly — the index parses it):

    ### <REF-ID>  <name>
    - WHERE: <url or book>
    - KIND: real | pixel
    - TEACHES: <one structural rule, one line>

No images are stored here. The best references online are other people's
copyrighted work; we link and we annotate, we do not copy bytes into the
repo. A cook opens the link, compares side by side, and writes down what
it took.
