# BUILD CALLING SCRIPT (the prompt book; rule 93, the coordinator's school round four, 10/10/26)

The facing page of the handoff. One row per planned ship, written by the LANE before it builds; the coordinator owns the order column only. A row changes, it never moves; a late insert is 14.5, never a renumber.

Row shape:
`CUE <n> | <LANE> | <what lands, one line> | FIRES ON: <the splash stamp it lands under> | NEEDS: <cue it fires after, or none> | STATE: WARNING / STANDBY <sha> / GO <minute> / LANDED <sha> / SCRUB / FLOAT`

The words (rule 93): WARNING, the lane, at round start ("this lands after cue N"). STANDBY, the lane: suite green once, buildstamp bumped, sha in the row, nothing pushed to the demo. GO, the demo's cut only, the coordinator at the sweep or RUN after writing the report when no sweep has come within a round. LANDED, the pages run SUCCESS containing the sha. SCRUB, revert as the next push, no fix-forward; two scrubs on one cue ends it for the round. FLOAT, a cue the demo can drop; scrubbed first. The word GO appears only in a STATE column; talking about it, write G-O.

The holds: T-9, before a G-O the caller opens the live link and reads the splash stamp (the lane's suite green within 60 minutes; the NEEDS cue LANDED; the live stamp equals the stamp the row fires on; one out, no G-O). PLACES, 15 minutes before any reply to Paolo the coordinator issues no G-O, confirms the last pages run is SUCCESS and contains the last called sha (merge-base, never eyeballed), and watches the first 60 seconds on the phone profile: his VAMILY always lands on a called, seen build.
