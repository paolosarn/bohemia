## 1. THE DEMO IS NEVER HELD FOR MORE CONTENT
What exists today is the demo. It goes into a friend's hands now, not when the
game is finished. "There's so much to do" is the reason, not the excuse: every
other chat keeps building while the demo that exists is walked, handed over,
and watched. The RUN lane's first job is HANDS-NOW: walk today's demo on a real
phone, fix only what stops a stranger reaching the first fight, hand the link
to one friend, write down what they did. Nothing waits behind it and it waits
for nothing.

## 2. RELEASE IS FOLDED INTO THE RUN
The coordinator opened a RELEASE lane on 9/4 (the demo as a product). Paolo
was right: it was the same job THE RUN already had. THE RUN owns the thing you
play from the front door to a friend's phone: the walked surface, the save, the
demo cut, the friend rounds, and seeing what a friend did. One chat, one seam.
RELEASE existed one day and is closed; its jobs live in RUN. THE RUN is being
renamed by Paolo ("it was your name not mine"); the section stays RUN until he
picks, and the chat finds itself by its number, 01.

## 3. THE PLUMBER: THE PERMANENT PIPE FIXER
Chat 18 (the coordinator called it GATEKEEPER for a day; Paolo's word is the
pipe fixer, so PLUMBER) is a permanent lane with three jobs and no others:
- **SMALL AND FAST.** The game runs at 60 on a real phone, walking and in the
  fight at 120 BPM; loads fast; stays small. It measures first, writes the
  number, sets a budget, and builds the gate that holds the budget. It may
  shrink or speed up engine code only where a measurement says so, only where
  no gate changes colour, with before and after numbers in the commit.
- **EVERY RULE HAS A WORKING CHECKER.** About 230 gates; the whole set finishes
  in one command in under ten minutes; a gate that cannot say what law it
  enforces and what makes it red is retired with a record; the missing
  checkers (OWED, the board, the reference check) get built.
- **THE PILES GET ARCHIVED.** The handoff and the backlog, verbatim moves only.
It never builds features, never touches art or laws, never cleans other chats'
game code for style. A red gate it finds in another lane's work becomes one
line in that lane's section, never a fix by this chat.
