TWO WERE THE RULER, AND THE GATE'S OWN LAW SAYS SO
--------------------------------------------------
  1. A CHECKER THAT CANNOT TELL A MENTION FROM A USE IS THE BROKEN ONE (8/1). The
     sweep decided a tool "draws" by searching the WHOLE FILE for fillRect / drawImage
     / putImageData -- including its DOCSTRING. bohemia_sun_mode_char_patch.py is a CSS
     class flip that draws nothing at all; it merely EXPLAINS in prose why an element's
     background shows through a putImageData with alpha 0, and for that sentence it was
     held to the art-cooking law and reported as failing it. The test now strips the
     module docstring first. EMBEDDED JS IS NOT STRIPPED -- these patch tools inject
     drawing code as string literals, which is a real use, and bohemia_family_cast_patch
     is still swept for exactly that.
  2. THE MARKER, NOT ITS PUNCTUATION. The regex demanded a colon IMMEDIATELY after the
     words, so a block headed `REUSE CHECK (REUSE-FIRST, Paolo 7/22):` -- a thorough
     one, naming what it opened and why -- read as ABSENT. Citing the law you are
     complying with is this repo's own habit and the gate was failing files for it.
     An attribution in the heading is now tolerated; the heading must still be one
     line, and every bank claimed inside the block is still opened-and-verified.
  NOTHING IS WEAKENED. Mutation-tested three ways, all correct:
     delete a real block                    -> red, naming the file
     a NEW patch tool that draws in CODE    -> red, naming it (no hole was opened)
     a tool that mentions drawing in PROSE  -> correctly not swept
