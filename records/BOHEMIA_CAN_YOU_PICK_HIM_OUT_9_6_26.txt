Q1. DOES A BODY LOOK ANY DIFFERENT ONCE IT IS YOUR ENEMY?

  Same crowd, same bodies, THE SAME FACING ASKED FOR BOTH TIMES, matched by id.
  And it is run against a NULL CONTROL that spans REAL TIME: several sweeps with
  waiting between them and nothing else happening, every pair compared, so the
  noise a body shows on its own is a measured number and not an assumption.
  (An earlier version took two sweeps back to back, reported zero drift, and was
  therefore controlling for less time than the test it was controlling for.)

  NOT ONE BODY IN 172 CHANGED BY A THOUSANDTH OF A SHADE.

  AND A RULER THAT REPORTS ZERO FOR EVERYTHING IS NOT EVIDENCE, so here is the
  POSITIVE CONTROL that shows this one can see a difference when there is one:
  the SAME measurement, on the same bodies, through the same code, separates the
  crowd into 24 distinct values spanning 37.3 shades (Q2 and Q3 below). It is
  wide awake. It returns zero for the before-and-after comparison because there
  is nothing there to see.

  THE CODE SAYS THE SAME THING, so this is not an accident of one crowd: a
  body's sprite comes from ctBody(), which asks ctFactionOf() and then
  ctFitIndex() -- faction, else trade, else id. ctAgainstMe is called in exactly
  FOUR places in the walked city and NOT ONE is the appearance path: it drives
  following, blocking, the bark and the bump. THE VALUE CHANNEL CARRIES NO
  INFORMATION ABOUT WHO IS DANGEROUS, because nothing is asking.

  *** AND THE FIRST VERSION OF THIS MEASUREMENT SAID THE OPPOSITE. *** Read at
  each body's REAL facing it reported all 172 bodies changing value, which
  contradicts the code path -- and the contradiction was the tell, not a
  discovery. 152 of them HAD TURNED TO LOOK AT ME, which is the watch behaviour
  PEOPLE shipped working exactly as designed, and a body seen from another side
  is another sprite. Of the 20 that did not turn, ZERO moved. The ruler was
  measuring the turn. WHEN A NUMBER CONTRADICTS THE CODE, SUSPECT THE NUMBER.

  HONESTLY, ABOUT THIS CROWD: every body on the glass witnessed the deed, so all
  172 turned at once and the reason is "you" -- personal, not faction. In real
  play you earn a few enemies, not a street. That does not weaken Q1, which asks
  whether the SAME body looks different. It does mean this crowd cannot answer
  "does a hostile stand out from civilians", because after the deed there are no
  civilians left to stand out from. That needs a mixed crowd and it is the ship
  test for the fix, not for the measurement.

Q3. HOW MANY DIFFERENT BODIES IS THE CROWD ACTUALLY MADE OF?

    distinct body values among 172 bodies   24

    THE CROWD IS QUANTISED: it is drawn from a small set of baked bodies, so
    many people share a value exactly. That decides where the fix can live --
    a shift baked into a shared sprite would move everybody wearing it, so
    whatever carries the step has to be applied PER BODY AT DRAW TIME.
