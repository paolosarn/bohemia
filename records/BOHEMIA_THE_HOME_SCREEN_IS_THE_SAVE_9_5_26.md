# THE HOME SCREEN IS THE SAVE (RUN, 9/5/26)

VAMILY `[home screen]` / BB-HOME-SCREEN-IS-THE-SAVE.

## THE PLATFORM PUT A RUN TIMER ON A GAME WHOSE FIRST LAW IS THAT THERE ARE NO RUNS

Since iOS 13.4 / Safari 13.1, WebKit deletes **all** of a site's script-writable
storage — localStorage, sessionStorage, IndexedDB, service worker registrations
— after seven days of browser use without interaction on that site. No amount of
code beats it.

**The row asked, in capitals, to re-check the rule before doing anything, because
the last reader could not confirm it was still current. So I did.** It is still
current: WebKit's storage policy was revised through Safari 17 and the 2023
storage-policy update, and what changed was the *quota* rules. The seven-day
deletion did not change.

The exemption is still the same one and still the only one: a web app added to
the **home screen** is not part of Safari and keeps its own counter of days of
use, which resets every time it is used — WebKit engineer John Wilander's own
words, *"we do not expect the first-party in such web applications to have its
website data deleted."*

**Honest limit, because the row asked for honesty about the source:** that
exemption is an engineer statement plus long-standing behaviour, not formal
documentation, and no 2026 source restates it. `navigator.storage.persist()` is
a second lever with exactly the same status — reported to help, not documented
to. We already request it; that is right, and it is cheap.

**So add to home screen is not a convenience feature. It is the save.**

## *** AND THE INSTALL PATH LANDED A FRIEND IN THE WORKSHOP ***

Measured: `BOHEMIA_DEMO.html` linked `bohemia.webmanifest` — **the same file the
alpha links** — whose `start_url` and `id` are `BOHEMIA_ALPHA_0_9.html`.

So a stranger who opened the demo link, added it to their home screen and tapped
the icon got **the seventeen-tab dev bench** instead of the game. Chrome honours
`start_url` outright; Safari has honoured web app manifests since iOS 16.4. And
because `id` was the alpha's too, the two surfaces were **one app** to the
browser: installing either one blocked the other.

**Nothing anywhere read the manifest, so nothing went red, for months.** The
entire iOS save strategy — the one thing standing between a hundred hours and a
platform rule — hung off a door that opened onto the wrong room.

## WHAT WAS ALREADY RIGHT

Most of this row was already built, and finding that out was most of the work.
The apple meta tags, the touch icon, `navigator.storage.persist()` requested with
a measurable result, `BohemiaSave.status()` computing `evictionRisk` off
`navigator.standalone`, and the true sentence it prints — *"Safari erases it
after 7 days without a visit — add Bohemia to your Home Screen, or EXPORT
SAVE"* — all correct, all shipped. The ask rides on the reckoning card he already
reads, once, with `installAsked` in the save so it stays once across reloads.

**How loud the ask should be is his**, and the row says so. Nothing here changes
its size.

## WHAT SHIPPED

**The demo has its own manifest, generated by the cut.** `start_url` and `id`
point at the demo. The cut owns it the same way it owns the tabs — it is a
reachability change, not a rewrite — and the cut's own `--check` covers it, so it
cannot drift silently.

**`gates/home_screen_is_the_save_gate.js`, 27 checks, registered INSTALL PATH.**
It holds both surfaces, and it reads the manifest **the way the browser does** —
fetched and parsed at runtime — rather than off the source text, because a
manifest that 404s reads exactly like a manifest that is fine when you only grep
for the link tag.

### And it is not a duplicate, which I checked before building

`gates/home_screen_gate.js` (registered HOME SCREEN) already holds the **alpha's**
manifest, its icons, that every icon publishes, and the nothing-saved messaging
on a home-screen launch. It never looks at the demo. Mine is the demo half plus
**the relationship between the two surfaces** — that they are two apps and not
one — which is exactly what no single-surface gate can see, and exactly where the
bug was.

Mine was first registered as HOME SCREEN and collided with it. Renamed to
INSTALL PATH: two gates with one name is its own quiet way to lose one.

### Mutation proof

Point the demo's manifest link back at the workshop's — the bug precisely as it
stood an hour earlier — → **4 red**, including the browser's own fetch reading
`start_url BOHEMIA_ALPHA_0_9.html`.
