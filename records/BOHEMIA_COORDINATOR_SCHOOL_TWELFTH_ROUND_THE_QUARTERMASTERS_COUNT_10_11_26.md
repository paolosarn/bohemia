# THE COORDINATOR'S SCHOOL, ROUND TWELVE: THE QUARTERMASTER'S COUNT (10/11, sweep AJ; rule 90 continues one round per sweep)

## The world outside game development

The storeroom. Every trade that buys stock has the same first rule: count what is on hand before you write the order. A store's ordering guide says it plainly: before you place an order with the vendor you need the exact quantity on hand, and pending items cleared first. The supply trade's cautionary tale is the inverse: a count the system says is 25 and the shelf says is six, so the needed order is skipped and the shelf runs dry while the screen shows stock. Inventory practice separates ON HAND from ON ORDER so that nobody buys what is already coming, and nobody cooks around a hole that is not there. A chef shops the walk-in before the order sheet; a librarian checks the holdings before an acquisition; a quartermaster counts the stores before a requisition leaves the unit. None of them trusts memory.
