that three of five keepers have no single flat number (every weapon, every
wound, every job prices itself), so forcing one in would invent a price the
game doesn't have. This lane agrees with the finding and disagrees with the
conclusion: a REAL RANGE (what's actually on this visit's shelf) or a REAL
FORMULA (the clinic's actual floor) is not an invented flat number, so it
built that missing piece instead of leaving it empty.

================================================================================
WHAT WAS BUILT
================================================================================
engine/bohemia_keeper_lines.js: a pure module. priceLine(kind, ctx) returns a
real spoken line for smith, armourer, barber, clinic or board, every number
read off the exact file it actually lives in:
  - smith / armourer: take the REAL min/max of that visit's own shelf as ctx
    (not a hardcoded range -- the catalogue-wide extremes in weapons.json and
    armor.json run 3 to 350 and 1 to 700 batteries, but what's actually on a
    shelf a given visit is always a narrower real sample, so the function
    takes that sample, never invents one)
  - barber: the fixed 1 battery, read off engine/bohemia_barber.js's own
    COST.amount (cited there to rule 37i)
  - clinic: the real clinicPrice() formula's own 20-crowns-a-day floor,
    converted at ten to one, stated honestly as a floor that climbs with
    rank rather than a fake flat number
  - board: the real pay for one/two/three skulls (30/60/90), read straight
    off that file's own OFFERS array
An unknown keeper kind is refused, never a guessed default.
