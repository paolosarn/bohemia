# THE TUTOR: WHAT TEACHES THE CHATS TO MAKE GOOD ART AND SOUND, WITH NO GPU AND NO SUBSCRIPTION (research round three, 10/10/26)

## HIS WORDS (verbatim, above)
"There has to be some simple coding source, something that you could buy or download to like understand what needs to happen, like maybe it's like a teacher, tutor for you or something. I don't know. I don't want to keep my graphics cards on my computer, so that's not gonna be an option."

Rulings carried in: no subscriptions, no outside per-call credits, no graphics card. Everything below is a one-time buy or a free download, and every tool runs on a plain CPU inside the chats' containers.

## THE SHORT ANSWER
Yes, a tutor exists, and it is three things bolted together: a written rulebook the chats load as a skill, a set of CPU tools that draw and check pixels for them, and a gate that throws out the usual mistakes. The rulebook is cheap: one $10 book plus free tutorials that are legally reusable, turned into checklists. The tools are cheap too: Aseprite is $19.99 once and runs headless in a container, and several open MCP servers already let a Claude agent drive it and measure what it drew. What does not exist is a free, no-GPU way to make finished pixel art from a text prompt at our quality; CPU image models run, but nobody has shown good 96 px tiles from them, and nothing in them teaches taste. The honest limit is that knowledge plus tools raises the floor and stops the seventh-grader tells, while the ceiling still comes from one paid pixel artist whose hero set the chats then extend by rule.

## A. KNOWLEDGE AS A SKILL

**How a skill loads.** A skill is a folder with one SKILL.md file: YAML frontmatter (name, description) and Markdown instructions, with optional scripts/, references/ and assets/ folders. The agent preloads only every skill's name and description; when a task matches, it reads the whole SKILL.md and opens the bundled files only as needed. Claude Code's docs say keep SKILL.md under 500 lines and push detail into referenced files. The format is an open standard at agentskills.io, published by Anthropic in December 2025. Official repo: https://github.com/anthropics/skills, docs at https://code.claude.com/docs/en/skills and https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview. So the "tutor" is literally a folder in our repo that every chat reads before it draws.

**Pixel-art skills people already published** (free, varying depth):
- omer-metin/skills-for-antigravity pixel-art: the deepest found; covers dithering, palettes, selective outlining, hue-shifted ramps; installs with `npx skills add` into .claude/skills/. https://skillselion.com/skills/omer-metin/skills-for-antigravity/pixel-art
- chasexu168340-rgb/codex-skills pixel-art: NES/SNES/HD-2D notes, draws on Pedro Medeiros. https://github.com/chasexu168340-rgb/codex-skills/blob/main/pixel-art/SKILL.md
- mcpmarket pixel-art-generator: silhouette, base fill, details, shading, as JSON pixel data. https://mcpmarket.com/tools/skills/pixel-art-generator
None of these knows our 96 px, 45-degree packs. They are a starting template, not our tutor.

**MCP servers that give the agent pixel tooling** (all open source, all drive Aseprite in batch mode, no display, no GPU):
- MalloyTheDev/aseprite-mcp (MIT): about 156 to 163 tools; `assess_sprite` scores noise, jagged diagonals, centring and palette conformance against a declared ramp; `diff_sprites` compares two frames; `validate_loop` checks a cycle. Needs Aseprite 1.3+, Python 3.10+. https://github.com/MalloyTheDev/aseprite-mcp
- jcscocca/aseprite-mcp: every edit is a generated Lua script run through `aseprite -b --script`. https://github.com/jcscocca/aseprite-mcp
- Also Vollkorn-Games/aseprite-mcp (Node), diivi/aseprite-mcp (Python, 104 tools), willibrandon/pixel-mcp (palettes, dithering, sheets). https://github.com/diivi/aseprite-mcp https://github.com/willibrandon/pixel-mcp

**The teaching to turn into the skill:**
- Pixel Logic by Michael "Michafrar" Azzi: $10+ on Gumroad (https://michafrar.gumroad.com/l/pixel-logic), 43 MB PDF, 2022 edition free to past buyers. Copyright page: no part reproduced without written permission. So the PDF itself stays off the repo; a rules file written in our own words from what it teaches (clusters, anti-aliasing, dithering, outlines, sub-pixel animation, colour ramps) is ordinary learning and fine. The chapter list could not be fetched this round (site unreachable from the container).
- Saint11 (Pedro Medeiros, Celeste): free, Creative Commons Attribution 4.0, so the images and text CAN be copied into a skill with credit. https://saint11.art/blog/pixel-art-tutorials/ and https://github.com/saint11/Saint11Tutorials
- Slynyrd's Pixelblog (Raymond Schlitter): free to read on Lospec; palettes (slynyrd 128), texture, trees, grass, top-down and side-view houses. Licence not stated; derive rules, do not copy images. https://lospec.com/pixel-art-tutorials/author/slynyrd
- Lospec palette list: free .hex/.gpl/.pal downloads and an API; per-palette licence not confirmed. https://lospec.com/palette-list
- Brandon James Greer: free YouTube, youtube.com/@BJGpixel; video, so an agent gets rules only via a human's notes.
- Pixel Art Academy: Learn Mode, $13 on Steam, Early Access, teaches lines only so far; a game for a human, useless to an agent. https://pixelart.academy/

## B. ASEPRITE AND THE DETERMINISTIC TOOLS WITHOUT A GPU

**Aseprite headless.** `aseprite -b` (batch) never starts the UI; `--script x.lua` runs Lua with `--script-param` values; the CLI exports layers, tags, sheets and JSON (https://www.aseprite.org/docs/cli/). A script can read and write pixels, set palettes, build and slice sheets, and export 8-direction sheets by tag. Batch gotchas measured by the MCP projects: the "current palette" is not the sprite's, cel images are cropped to their bounds so writes outside do nothing, and every UI object is nil. Docker recipe: kidthales/docker-aseprite-headless builds v1.3.15+ from source on Debian Trixie and runs `--batch file.aseprite --save-as out.png` (https://github.com/kidthales/docker-aseprite-headless).

**EULA.** The current EULA lets you compile and modify the source for your own personal purpose; you may not distribute copies or compiled binaries to third parties, and art you make is yours for any commercial product (https://github.com/aseprite/aseprite/blob/main/EULA.txt, https://www.aseprite.org/faq/). The clean move: buy one $19.99 licence (official site, Steam, itch.io, one-time) and build from source inside our own containers, never publishing the binary.

**Free equivalents.** LibreSprite (GPL fork of old Aseprite) has `--batch`, `--script` (JavaScript) and `--save-as`, but issue #305 says it wants an SDL context even for CLI, so headless needs Xvfb (https://github.com/LibreSprite/LibreSprite/issues/305). Pixelorama (Godot, free) has `--headless -- --export --output`, but issue #1625 says `-o` fails silently headless on v1.2.3 (https://github.com/Orama-Interactive/Pixelorama/issues/1625). Paid Aseprite is the one that just works.

**Maps and autotiles.** Tiled is free; `tiled --export-map` needs `xvfb-run` on Linux; `tmxrasterizer` renders any map to PNG with `--show-layer`/`--hide-layer` (https://doc.mapeditor.org/en/stable/manual/export-image/). Tilesetter: $12.99 once on itch.io with Steam key, free tier, GUI only (https://led.itch.io/tilesetter). Sprite Fusion: free web, desktop $12 to $15 one-time, GUI (https://www.spritefusion.com/). TilePipe: free, rule-based, builds 47-blob subtiles from tile parts (https://github.com/aleksandrbazhin/TilePipe). FabriceLing/autotile: Python, command line (https://github.com/FabriceLing/autotile). blobsmith-autotile-wirer: MIT 47-blob sheets (https://github.com/leobaray/blobsmith-autotile-wirer). A seam test is a 20-line Pillow script: tile the PNG 3x3 and diff the edges; nothing to buy.

## C. GENERATION WITHOUT A GPU, HONESTLY (numbers)

FastSD CPU (https://github.com/rupeshs/fastsdcpu) is the real project. Its own benchmarks, all on an Intel Core i7-12700 at 512x512: SD-Turbo one step, 7.8 s PyTorch, 5 s OpenVINO, 1.7 s with the TAESD tiny decoder; SDXL-Turbo 5.6 s OpenVINO, 2.5 s with TAESDXL; SDXS-512-0.9 0.82 s. A shared cloud CPU is slower than that desktop chip, so budget 5 to 30 s per 512 px image. The catch: those fast models are not pixel-art models. The pixel-art LoRAs people use (nerijs/pixel-art-xl) sit on SDXL, and the Hugging Face tutorial warns inference on CPU "could take a long time" and needs a lot of memory; the only timings found were GPU (2 s on a 4090) and 45 s on an M-series Mac. No report was found of anyone getting usable 96 px 45-degree tiles from a CPU run after palette snapping. Free to try, not proven; the earlier rounds' services are out by his ruling.

**No-model generation, all CPU and free:**
- Wave Function Collapse (mxgmn, MIT): bitmaps and tilemaps from a single example; the overlapping model takes one image and makes more that are locally similar; JS ports exist. https://github.com/mxgmn/WaveFunctionCollapse
- EmbarkStudios texture-synthesis (Rust, MIT, CLI): example-based synthesis with guided and multi-example modes; good for ground, rubble, rust. https://github.com/EmbarkStudios/texture-synthesis
- Pyxelate (Python, CPU): downsamples any image to pixel art with a learned palette and dithering. https://github.com/sedthh/pyxelate
- "Make Your Own Sprites" pixelization (Wu et al., ACM TOG 2022), code at https://github.com/WuZongWei6/Pixelization; a trained network, CPU feasibility not confirmed.
These make textures and variants from what we already own. They do not invent a character.

## D. SOUND WITHOUT A GPU OR A SERVICE

This half is solved. Sonniss GDC bundles (https://gdc.sonniss.com/): free, royalty-free for games, no attribution, lifetime, licence v2.0 effective 27 August 2026 bans AI training and standalone resale (https://sonniss.com/gdc-bundle-license/). Freesound.org: per-sound Creative Commons (CC0, CC-BY, CC-BY-NC); filter to CC0 or CC-BY and log credits. Processing: Spotify Pedalboard (GPL-3, Linux wheels, loads VST3 plugins and runs in a plain Python process; https://github.com/spotify/pedalboard), SoX and ffmpeg for layering, pitch, convolution. Chow Tape Model: free GPL-3 VST3/LV2 Linux build (https://github.com/jatinchowdhury18/AnalogTapeModel); no offline-render CLI target found, and a 9-year-old JUCE note says plugin clients may still want X11, so load it through Pedalboard with Xvfb or use Pedalboard's own Distortion, Compressor, Reverb, Bitcrush and a tape-wobble LFO written in NumPy; a headless alternative host is shakfu/minihost. UI blips: jsfxr's `sfxr-to-wav` Node script renders any sfxr.me definition to WAV (https://github.com/chr15m/jsfxr); bfxr2-cli is a CLI with templates like pickup_coin built for agent skills (https://github.com/osiriswd/bfxr2-cli); ChipTone is free, browser or desktop, CC0 output, no CLI (https://sfbgames.itch.io/chiptone). Teaching: The Game Audio Tutorial (Stevens and Raybould), used from about $12 on AbeBooks (https://www.abebooks.com/9780240817262/Game-Audio-Tutorial-Practical-Guide-0240817265/plp); A Composer's Guide to Game Music (Winifred Phillips), $29.95 MIT Press, ebook $19.99 (https://mitpress.mit.edu/9780262534499/a-composers-guide-to-game-music/); free: Akash Thakkar's YouTube channel and podcast, the GDC TUNIC audio talk (https://www.classcentral.com/course/youtube-the-tunic-audio-talk-262899), the Game Audio Learning Portal foley page (https://www.gameaudiolearning.com/knowledgebase/how-to-record-foley-for-games). Marshall McGee: not found this round.

- Carrd artist: walk/run cycle $80 to $95+, attack or jump $100+. https://doekittypixelcommissions.carrd.co/

**The brief** (from the pixel outsourcing guide and the game-art brief guide, https://gameartservices.com/blog/pixel-art-outsourcing-guide and https://www.gamedeveloper.com/design/crafting-the-perfect-game-art-brief): exact pixel resolution, every animation and frame count up front, the hex palette as the strongest style spec, examples at target resolution from our 87 packs, light direction and the 45-degree camera, negative references, annotated images. Ask for flat swatches with hex callouts so the chats colour-pick without drift, and pay for the .aseprite source files so layers and tags feed the headless pipeline.

## F. THE TUTOR IN OUR REPO (the design, priced one-time, what it can and cannot do)

**The design.** One skill folder, `skills/pixel-tutor/`, with a SKILL.md under 500 lines and these references: the measured rules of our 87 packs (palette ramps as .gpl, outline weight, light from the top-left, the 45-degree floor-to-wall ratio), the Pixel Logic techniques rewritten as checklists (cluster size, when to anti-alias, banding, pillow shading, dithering only on large flat areas, selective outlines, sub-pixel steps for slow motion), the Saint11 tutorials copied in with CC-BY credit, a before/after sheet template, and the sound half (layering from Sonniss, a Pedalboard tape-and-crush chain, the sfxr grammar for UI). Beside it, deterministic CPU tools the skill names by command: Aseprite headless in the container (one $19.99 licence, built from source, binary never published), the MalloyTheDev aseprite-mcp for `assess_sprite`, `diff_sprites` and `validate_loop`, Pyxelate for palette snapping, texture-synthesis and WFC for ground variants from pack samples, FabriceLing/autotile or TilePipe for 47-blob sets, a Pillow seam test, Tiled's tmxrasterizer for map proofs, Pedalboard plus SoX for sound. A gate, `pixel_tutor_gate.py`, rejects the tells: colours outside the declared ramp, orphan pixels, jaggies on 45-degree lines, pillow shading (lighter ring around a centre), mixed outline weights, a loop whose last frame repeats the first, any sound without a real recorded layer. Then one artist commission for the hero set (one character at 8 directions with walk and attack, one ground and wall tileset, one prop set, one portrait), delivered as .aseprite with palette and tags, which the chats extend by recolour, autotile, mirror, frame-diff and seam test, never by freehand.

**One-time price.** Pixel Logic $10; Aseprite $19.99; Tilesetter $12.99 (optional, GUI); the two audio books about $42 (or $12 used for one). Software and books total under $90. The artist hero set: $800 to $2,500 depending on the artist. Everything else is free and MIT, GPL or CC.

**What it can do.** Make every chat draw to the same measured rules; catch the seventh-grader tells before he sees them; turn one artist's set into hundreds of consistent tiles, directions and recolours; make the sound half fully professional from recordings and CPU processing. **What it cannot do.** It cannot give a text-only agent an eye; the agent still draws by numbers and sees by measurement. It cannot invent a new hero face or a new silhouette at artist quality without the artist. It cannot run a pixel-art image model well on CPU; that stays unproven. And a rulebook nobody enforces is a comment, so the gate is the part that makes it real.

## FOR PAOLO, IN PLAIN WORDS
The tutor is real: a rulebook the chats read before they draw, plus cheap tools that draw and measure pixels on a normal computer, plus a checker that throws out the ugly stuff. No graphics card, no monthly bills, and the whole kit of software and books is under 90 dollars. The one thing money can still not replace is a human pixel artist for the first hero set, roughly 800 to 2,500 dollars once, and the chats then copy its style by rule. Buy first: the Pixel Logic book, 10 dollars.
