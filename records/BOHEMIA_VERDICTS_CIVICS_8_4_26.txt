  2. THE DOOR PLANE       a bare x and a bare y-range, with nothing checking a wall was

  4. THE PLOT RECTANGLE   every builder guessed (-3,-3,15,15) whatever it actually built,

  6. THE PALETTE EXEMPTION legendOk said "if(c!==0 && ...)" -- it exempted code 0 BY NAME,
