PAOLO 10/4: "you told me to start talking to these chats... and they don't have jobs, so what the fuck is
wrong with you." Rule 74, A JOB IS AN OPEN ROW: every running lane has at least three OPEN rows at every
moment; 'round N open' inside a shipped row is never written again; a MODE line never names one row; and
"PLUMBER owes [open row gate]". Until now the only check was the coordinator's own sweep script.

## THE ANSWER FIRST

**gates/open_row_gate.js, in the suite as EVERY RUNNING LANE HAS A JOB.** It reads VAMILY.md the way a
chat reads it: a lane is a `## ` section with a MODE line (SHARED is a pool, not a lane), it is running
unless its MODE says PAUSED or PARKED, and a job is a line that starts `- OPEN`. Red names the lane.

| leg | today (23 running lanes) |
|---|---|
| O1 every running lane has at least one OPEN row | **green**: no lane is without a job |
| O3 at least three (rule 74's number) | **red**: WORLD 2, RUN TWO 2, ECONOMY 2, MODS 2 |
| M1 no MODE line names one row | green |
| R1 no SHIPPED row says ROUND n OPEN | **red**: SOUNDS ("ROUND THREE OPEN"), RUN TWO ("ROUND FOUR OPEN") |

The board moved while it was being measured: the first count found six lanes short of three (COMBAT TWO,
PORTRAIT and TUNING got their third row within the hour), the committed one four. That is the board
working, and it is why the gate reads the file at the moment it runs instead of a number written here.
